# 國考藥理筆記

以 **106–115 年（共 20 次）醫師第一階段「醫學（二）」**考古題為基礎，依考點整理的藥理學閱讀筆記。

| 項目 | 說明 |
|---|---|
| 題目來源 | 考選部「考畢試題查詢平臺」公告之試題、標準答案與更正答案 |
| 範圍 | 醫學（二）第 51–75 題（藥理），每次 25 題 × 20 次 = **500 題** |
| 題號格式 | `115-1 #65` = 115 年第一次考試第 65 題 |
| 答案 | 依考選部標準答案；有更正者另註明 |

## 怎麼用

1. 先看每章開頭的**考頻表**，決定讀的優先順序
2. 讀**核心表格**（概念＋臨床連結）
3. 展開**歷屆考題**自我測驗，答案與解析預設收合
4. 在綠色的 **我的筆記** 框裡直接加自己的筆記（編輯對應的 `.md` 檔）
