## 一、受體與訊息傳遞

### 1.1 重點整理

| 受體 | G 蛋白 | 第二傳訊 | 主要部位與作用 |
|---|---|---|---|
| M1, M3, M5 | Gq | ↑IP3/DAG → ↑Ca²⁺ | M3：平滑肌收縮（支氣管、膀胱逼尿肌、腸）、腺體分泌、瞳孔括約肌、睫狀肌；內皮 → NO → 血管舒張 |
| **M2**, M4 | **Gi** | ↓cAMP、開 K⁺ 通道 | M2：心臟（↓HR、↓AV 傳導） |
| α1 | Gq | ↑Ca²⁺ | 血管收縮、瞳孔放大肌（mydriasis）、膀胱頸／三角區與攝護腺收縮、豎毛肌 |
| α2 | Gi | ↓cAMP | 突觸前 → ↓NE 釋放；中樞 → ↓交感輸出 |
| β1 | Gs | ↑cAMP | 心臟 ↑HR／收縮力、腎 JG cell ↑renin |
| β2 | Gs | ↑cAMP | 支氣管、子宮、骨骼肌血管舒張；肝醣分解；K⁺ 入細胞 |
| β3 | Gs | ↑cAMP | **膀胱逼尿肌舒張**、脂肪分解 |
| D1 | Gs | ↑cAMP | 腎、腸系膜血管舒張 → 利鈉 |
| D2 | Gi | ↓cAMP | 中樞；腸胃道 ↓蠕動（拮抗劑才是 prokinetic） |
| Nn / Nm | — | 配體門控 Na⁺/K⁺ 通道 | 自主神經節、腎上腺髓質／神經肌肉接合 |

!!! tip "高頻陷阱"
    - **膀胱**：逼尿肌收縮 = M3、舒張 = β3；α1 作用在**膀胱頸／三角區**，不是逼尿肌
    - **眼睛**：散瞳（α1，瞳孔放大肌）≠ 睫狀肌麻痺（抗 M3）。擬交感藥只散瞳、**不造成 cycloplegia**
    - cGMP 路徑：NO（nitroprusside）→ 可溶性 GC；ANP → 膜上 GC；sildenafil 抑制 PDE5。**isoproterenol 只增加 cAMP**

### 1.2 歷屆考題

??? question "108-1 #58｜活化哪種自主神經受體通常會抑制 adenylyl cyclase？"
    A. M2 muscarinic　B. M3 muscarinic　C. β1　D. β3

    **答案：A** — M2 接 Gi → ↓cAMP。M3 為 Gq；β1、β3 為 Gs。

??? question "110-1 #65｜活化 α1 受體可能引起的反應，何者**錯誤**？"
    A. 膀胱逼尿肌收縮　B. 豎毛肌收縮　C. 骨骼肌中血管收縮　D. 心肌收縮力增強

    **答案：A** — 逼尿肌收縮靠 M3；α1 收縮膀胱頸。心臟也有少量 α1，可輕微增加收縮力。

??? question "115-2 #67｜活化哪種受體最能有效擴張支氣管？"
    A. α1　B. β2　C. M3　D. 5-HT3

    **答案：B**

??? question "109-1 #60｜下列何者**不會**增加細胞中 cGMP？"
    A. isoproterenol　B. sodium nitroprusside　C. sildenafil　D. ANP

    **答案：A** — isoproterenol（β1/β2 致效劑）→ Gs → cAMP。

??? question "106-1 #59｜哪種受體的訊息傳遞**不是**經由 G 蛋白？"
    A. muscarinic　B. glucagon　C. histamine　D. NMDA

    **答案：D** — NMDA 為離子通道型（nicotinic 也是）。

## 二、擬膽鹼藥（直接作用）

### 2.1 重點整理

| 藥物 | M 作用 | N 作用 | 被 ChE 分解 | 臨床用途 |
|---|---|---|---|---|
| Acetylcholine | +++ | +++ | +++ | 眼內手術縮瞳（局部） |
| Methacholine | +++ | + | + | 氣道過敏激發試驗 |
| Carbachol | ++ | +++ | — | 青光眼（局部） |
| **Bethanechol** | ++ | **—** | **—** | 術後／神經性**尿滯留**、腸麻痺 |
| **Pilocarpine** | ++（三級胺，入 CNS） | — | — | 青光眼（睫狀肌收縮→小樑網打開）、**Sjögren／放療口乾** |
| **Cevimeline** | M3 | — | — | Sjögren 口乾 |

!!! tip "記法"
    **Carba**mate 結構（carbachol、bethanechol）→ 抗 ChE 分解；**β-methyl**（methacholine、bethanechol）→ 降低 N 作用。bethanechol 兩者都有 → **最純 M、最耐 ChE**。

### 2.2 歷屆考題

??? question "110-2 #66｜何者活化 nicotinic 受體作用最弱，且最不易被膽鹼酯酶分解？"
    A. acetylcholine　B. methacholine　C. carbachol　D. bethanechol

    **答案：D**

??? question "108-1 #67｜直接作用型蕈毒鹼致效劑，可治療 Sjögren 或放療引起的口乾？"
    A. atropine　B. cevimeline　C. neostigmine（間接）　D. succinylcholine

    **答案：B**

??? question "115-2 #53｜關於 pilocarpine，何者**最不適當**？"
    A. 口服易腹瀉　B. 收縮睫狀體幫助房水排出→青光眼　C. 刺激唾液分泌→Sjögren　D. 口服可治療膀胱過動症

    **答案：D** — M 致效劑會**加重**逼尿肌收縮；OAB 要用抗蕈毒鹼藥或 β3 致效劑。

## 三、膽鹼酯酶抑制劑與有機磷中毒

### 3.1 重點整理

| 藥物 | 結構 | 入 CNS | 用途 |
|---|---|---|---|
| **Neostigmine** | 四級胺 | ✗ | 重症肌無力、**逆轉非去極化 NMB**、術後腸麻痺／尿滯留、**Ogilvie syndrome（急性結腸假性阻塞）** |
| Pyridostigmine | 四級胺 | ✗ | 重症肌無力**長期治療首選** |
| Edrophonium | 四級胺 | ✗ | 極短效：Tensilon test |
| Ambenonium | 四級胺 | ✗ | 重症肌無力 |
| **Physostigmine** | **三級胺** | ✓ | **抗膽鹼藥中毒**（atropine、TCA）；**不用於** MG |
| Donepezil／Rivastigmine／**Galantamine** | — | ✓ | **阿茲海默症**（galantamine 另有 nicotinic allosteric 作用） |
| 有機磷（parathion、sarin） | 不可逆磷酸化 | ✓ | 中毒 → **atropine + pralidoxime** |

**有機磷／ChEI 過量**：DUMBBELSS（Diarrhea, Urination, **Miosis**, Bronchospasm, Bradycardia, Emesis, Lacrimation, Salivation, Sweating）＋ N 作用（肌束顫動→無力）＋ CNS。

!!! tip "Pralidoxime（2-PAM）"
    - 在 **aging（老化）前**使 AChE 去磷酸化恢復活性
    - **四級胺 → 不易入 CNS**（diacetylmonoxime 為三級，CNS 穿透較好）
    - 對 **carbamate**（如 carbaryl）中毒無效、不建議使用
    - 過量本身可造成神經肌肉阻斷 → 肌無力
    - 主要恢復 NMJ（N 作用）功能；M 症狀仍要靠 **atropine**

### 3.2 歷屆考題

??? question "106-2 #56｜Neostigmine 過量中毒，**不會**產生哪個作用？"
    A. 腹瀉　B. 流汗　C. 散瞳　D. 排尿

    **答案：C** — 應為縮瞳。

??? question "111-1 #67｜何者**不適合**用於治療重症肌無力？"
    A. pyridostigmine　B. physostigmine　C. neostigmine　D. ambenonium

    **答案：B** — 三級胺入 CNS，副作用大；MG 用四級胺類。

??? question "114-2 #65｜Neostigmine **最不適合**治療哪個疾病？"
    A. 重症肌無力　B. 術後腸麻痺　C. 心搏過緩　D. 術後尿滯留

    **答案：C** — 會**加重**心搏過緩。

??? question "113-1 #68｜最適合改善住院病人急性結腸假性阻塞（Ogilvie）？"
    A. sucralfate　B. bismuth　C. neostigmine　D. metoclopramide

    **答案：C**

??? question "107-2 #67｜Galantamine（ChEI）最適合治療？"
    A. 重症肌無力　B. 帕金森氏症　C. 青光眼　D. 阿茲海默症

    **答案：D**

??? question "115-1 #73｜治療阿茲海默症的藥物，何者機制與其他三者不同？"

??? question "114-1 #65｜關於 pralidoxime，何者**最不適當**？"

    **答案：C**

## 四、抗蕈毒鹼藥

### 4.1 重點整理

| 藥物 | 特色 | 用途 |
|---|---|---|
| Atropine | 三級胺 | 心搏過緩、有機磷中毒、術前減少分泌、散瞳＋睫狀肌麻痺 |
| **Scopolamine** | CNS 作用強 | **動暈症**、腹痛腹瀉；**不可用於排尿困難** |
| **Ipratropium** | 四級胺、短效吸入 | COPD／氣喘支氣管擴張、減少黏液；**心律不整副作用少** |
| **Tiotropium** | 四級胺、**長效（t½ ≈25 h）、不入 BBB** | COPD 維持治療（LAMA） |
| Oxybutynin／Tolterodine | — | **膀胱過動症（OAB）** |
| **Darifenacin**／Solifenacin | **M3 選擇性**、長效，一天一次 | OAB、尿失禁 |
| Trospium | 四級胺，不入 CNS | OAB（老人較少認知副作用） |
| Tropicamide | 短效 | 散瞳檢查 |
| Benztropine／Trihexyphenidyl | 中樞 | 帕金森、EPS |
| Pirenzepine | M1 選擇性 | 消化性潰瘍（舊） |

**Atropine 中毒**：Hot as a hare、Dry as a bone、Red as a beet、Blind as a bat、Mad as a hatter；心跳快、**口乾（不會流涎）**、散瞳、尿滯留。

!!! danger "禁忌"
    **隅角閉鎖性（狹角）青光眼**：抗蕈毒鹼藥散瞳 → 虹膜堵住隅角 → 誘發急性發作。也**不能降眼壓**。攝護腺肥大病人小心尿滯留。

## 五、神經肌肉阻斷劑、肌鬆劑與神經毒素

### 5.1 重點整理

| 類別 | 藥物 | 重點 |
|---|---|---|
| 去極化 NMB | **Succinylcholine** | **作用最短**（plasma pseudocholinesterase 分解，5–10 min）；Phase I 肌束顫動；**高血鉀**、**惡性高熱**；**ChEI 會加強**（不能逆轉 Phase I） |
| 非去極化 NMB | Rocuronium、vecuronium、pancuronium、(cis)atracurium | 四級胺 → **不能口服**；**neostigmine（＋glycopyrrolate）或 sugammadex（rocuronium／vecuronium）逆轉**；rocuronium 肝代謝；cisatracurium 為 Hofmann 降解 |
| 惡性高熱解藥 | **Dantrolene** | 抑制骨骼肌 **RyR1** Ca²⁺ 釋放；誘因：吸入麻醉（halothane）＋ succinylcholine |
| 中樞肌鬆 | **Baclofen** | **GABA-B 致效劑** |
| | **Tizanidine** | **α2 致效劑**（不是拮抗劑！） |
| | Diazepam | GABA-A 正向調節 |
| 神經毒素 | **Botulinum toxin** | 切斷 SNARE → **抑制突觸囊泡釋放 ACh**（除皺、肌張力不全） |
| | Tetrodotoxin | 阻斷 **Na⁺ 通道** |
| | α-latrotoxin（黑寡婦） | 大量釋放 ACh |
| | ω-conotoxin | 阻斷 N 型 Ca²⁺ 通道 |
| 菸鹼受體 | **Varenicline** | **α4β2 nicotinic 部分致效劑**；戒菸效果優於 bupropion；副作用：焦慮、憂鬱、怪夢 |

### 5.2 歷屆考題

## 六、擬交感神經藥

### 6.1 重點整理

| 藥物 | 受體 | 重點用途／考點 |
|---|---|---|
| Epinephrine | α、β1、β2 | **過敏性休克首選**（生理性拮抗，非 H1 拮抗） |
| Norepinephrine | α1、β1 | 敗血性休克；反射性心跳變慢 |
| Isoproterenol | β1、β2 | ↑cAMP；心搏過緩 |
| **Dopamine** | 低劑量 **D1**（腎利鈉）→ 中劑量 **β1** → 高劑量 **α1** | **不會**透過 D2 增加腸蠕動 |
| Dobutamine | β1 | 強心（心衰竭） |
| **Fenoldopam** | **D1 致效劑** | **IV 治療高血壓急症**、腎血流↑ |
| Phenylephrine | α1 | 鼻塞、散瞳（不麻痺睫狀肌）、升壓 |
| **Midodrine** | α1（**前驅藥** → desglymidodrine） | **姿勢性低血壓**；**會升壓** |
| Ritodrine／Terbutaline | β2 | 抑制早產 |
| **Mirabegron**（vibegron） | **β3 致效劑** | **OAB**：舒張逼尿肌；副作用**高血壓**（不是低血壓） |
| Ephedrine／Pseudoephedrine | 間接＋直接 | 鼻塞；**會升壓** |
| Amphetamine、Modafinil | 間接（釋放／抑制再回收） | ADHD；modafinil → **嗜睡症（narcolepsy）** |
| Cocaine | 抑制 NE／DA 再回收 | 局部麻醉＋**血管收縮**；**與 heroin 無交叉依賴** |

## 八、交感神經抑制劑：α2 致效劑與 α 阻斷劑

### 8.1 重點整理

| 藥物 | 機轉 | 考點 |
|---|---|---|

| **Methyldopa** | 中樞轉換為 **α-methylnorepinephrine** | **懷孕高血壓**；**腎功能不全可用**；Coombs(+) 溶血 |
| Apraclonidine／Brimonidine | α2 致效（點眼） | 青光眼：↓房水生成 |

| **Tamsulosin**、silodosin | **α1A** 選擇性 | BPH；**白內障手術虹膜鬆弛症候群（IFIS）** |
| Phentolamine | 非選擇性 α（可逆） | 嗜鉻細胞瘤、NE 外滲 |
| Phenoxybenzamine | 非選擇性 α（**不可逆**） | 嗜鉻細胞瘤術前 |
| **Labetalol**、carvedilol | α1＋β | labetalol α 阻斷最明顯；懷孕高血壓 |

## 九、β 阻斷劑

### 9.1 重點整理

| 藥物 | 特性 | 考點 |
|---|---|---|
| Propranolol | 非選擇性、脂溶性 | **氣喘禁忌**；**甲狀腺風暴**；心房心律不整＋心肌梗塞後預防猝死；偏頭痛預防 |
| Metoprolol、atenolol、bisoprolol | β1 選擇性 | 心衰竭（metoprolol succinate、bisoprolol、carvedilol） |
| **Esmolol** | β1、**極短效**（紅血球酯酶，t½ ≈ 9 min） | **手術中／急性心律不整** |
| Timolol、**Betaxolol**（β1） | 點眼 | **隅角開放性青光眼**：↓房水生成 |
| Pindolol、acebutolol | ISA | — |
| Sotalol | β 阻斷＋第 III 類（K⁺） | — |
| Carvedilol、labetalol | α1＋β | — |

!!! tip "β-blocker 中毒 → **Glucagon**"
    glucagon 受體 → Gs → cAMP，**繞過 β 受體**提升心跳與收縮力（110-1 #75、113-1 #75 兩次考）。干擾選項：atropine、pralidoxime、theophylline、caffeine。

!!! tip "青光眼藥物一覽（常混在本章考）"
    | 機轉 | 藥物 |
    |---|---|
    | ↓房水生成 | β 阻斷（timolol、betaxolol）、α2 致效（apraclonidine、brimonidine）、碳酸酐酶抑制（acetazolamide） |
    | ↑葡萄膜鞏膜排出 | PGF2α 類似物（**latanoprost**） |
    | ↑小樑網排出 | M 致效（pilocarpine） |
    | ✗ 不能降眼壓 | **atropine**、tropicamide（禁用於狹角） |

## 十、跨章節：其他藥物的自律神經作用

### 10.1 重點整理

| 藥物 | 自律神經相關考點 |
|---|---|
