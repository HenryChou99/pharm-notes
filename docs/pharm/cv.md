# 心血管藥理

---

> 106–115 年 20 次考試、500 題藥理中，約 **68 題（≈14%）**屬心血管藥理（不含利尿劑），平均每次 3–4 題；另有 15 題心血管相關題已收錄在[自律神經藥理](ans.md)（β 阻斷、α2 致效、D1 致效等）。

## 一、抗高血壓藥

### 1.1 重點整理

| 類別 | 藥物 | 機轉 | 考點 |
|---|---|---|---|
| Renin 抑制劑 | **Aliskiren** | 直接抑制 renin | 唯一作用在 RAAS 最上游 |
| ACEI | Captopril、**enalapril** | 抑制 ACE → ↓Ang II、**↑bradykinin** | 乾咳、血管性水腫（bradykinin）；高血鉀；懷孕禁忌；**心衰竭減緩心室重塑** |
| ARB | Losartan、valsartan、candesartan | 阻斷 **AT1** | 少乾咳；valsartan 與 sacubitril 合用 |
| DHP-CCB | Nifedipine、amlodipine、felodipine、nicardipine | 阻斷 L-type Ca²⁺ 內流 | 只擴血管 → **反射性心跳加快**；踝部水腫 |
| | **Clevidipine** | 同上 | **半衰期最短（約 1 分鐘，血中酯酶）、只能 IV** |
| Non-DHP CCB | Verapamil、diltiazem | 心臟＋血管 | ↓HR、↓AV 傳導 |
| K⁺ 通道開啟劑 | **Diazoxide** | 開 **K_ATP** → 動脈擴張 | **抑制 insulin 釋放 → 高血糖**（也用於胰島素瘤低血糖） |
| | Minoxidil | 開 K_ATP | 多毛、水鈉滯留、反射性心跳快 |
| 直接血管擴張 | Hydralazine | 動脈擴張 | **藥物性狼瘡**（慢乙醯化者） |
| | Nitroprusside | 釋放 NO → ↑cGMP | 高血壓急症；cyanide 中毒；**不易產生耐藥性** |
| α1 阻斷 | Prazosin、doxazosin | — | 高血壓、BPH、Raynaud；**不用於 ADHD** |

!!! tip "高頻陷阱"
    - **ACEI vs ARB**：ACEI 會累積 bradykinin（乾咳、angioedema）；遺傳性血管性水腫用 **icatibant（B2 拮抗劑）**
    - **Diazoxide 與 sulfonylurea 相反**：一個開 K_ATP（↓insulin）、一個關 K_ATP（↑insulin）
    - **只能 IV 的降壓藥**：clevidipine、fenoldopam（D1）、nitroprusside、esmolol

## 二、肺高壓與血管擴張相關藥物

### 2.1 重點整理

| 路徑 | 藥物 | 重點 |
|---|---|---|
| PGI2 類似物 | Epoprostenol、**treprostinil**、**iloprost**（吸入）、selexipag（IP 受體致效） | 肺高壓 |
| Endothelin 受體拮抗 | **Bosentan**、ambrisentan、macitentan | 肝毒性、致畸胎；**不經 cGMP** |
| PDE5 抑制 | Sildenafil、**tadalafil** | ↑cGMP |
| sGC 刺激劑 | **Riociguat** | ↑cGMP |

!!! tip "PG 類似物對照（常混考）"
    | 藥物 | 類似物 | 用途 |
    |---|---|---|
    | Epoprostenol／treprostinil／iloprost | PGI2 | **肺高壓** |
    | Alprostadil | PGE1 | **維持動脈導管開放**、勃起障礙 |
    | Misoprostol | PGE1 | NSAID 胃潰瘍預防、配 mifepristone 墮胎 |
    | Dinoprostone | PGE2 | 引產、子宮頸成熟 |
    | Latanoprost／bimatoprost | PGF2α | 青光眼 |

    **增加 cGMP 的血管擴張劑**：nitrates／nitroprusside／molsidomine（NO→sGC）、riociguat（sGC）、ANP／BNP（膜 GC）、sildenafil／tadalafil（PDE5）。**Bosentan 不是**。

### 2.2 歷屆考題

??? question "108-1 #59｜PGI2 致效劑，可用於治療肺高壓？"
    A. treprostinil　B. alprostadil　C. misoprostol　D. latanoprost

    **答案：A**

??? question "110-2 #70｜最適合用來治療肺高壓？"
    A. latanoprost　B. zileuton　C. iloprost　D. dinoprostone

    **答案：C**

??? question "106-1 #67｜治療肺高壓藥物的作用機轉，**不包括**？"
    A. endothelin antagonist　B. phosphodiesterase E5 inhibitor　C. soluble guanylyl cyclase activator　D. CGRP antagonist

    **答案：D**（考選部更正：B、D 均給分）— CGRP 拮抗劑是偏頭痛用藥；B 選項題目寫成「PDE E5」所以也給分。

??? question "113-1 #63｜何者**不是**藉由增加細胞內 cGMP 使血管擴張？"
    A. molsidomine　B. bosentan　C. sodium nitroprusside　D. tadalafil

    **答案：B** — bosentan 為 endothelin 受體拮抗劑。

??? question "106-1 #55｜下列那一類藥物可以使血管擴張？"
    A. endothelin antagonists　B. kinin antagonists　C. neurotensin antagonists　D. vasopressin agonists

    **答案：A** — kinin（bradykinin）本身擴血管，拮抗它不會擴張；vasopressin 收縮血管。

## 三、抗心絞痛藥

### 3.1 重點整理

| 藥物 | 機轉 | 考點 |
|---|---|---|
| **Nitroglycerin**、isosorbide | NO → sGC → ↑cGMP | **主要擴張靜脈 → ↓preload**；**耐藥性**（需 8–12 h 無藥期）；**Monday disease**；與 PDE5 抑制劑併用嚴重低血壓；顱內壓高禁用 |
| **Molsidomine** | **prodrug**，提供 NO | ↑**cGMP**（不是 cAMP） |
| **Nicorandil** | 開 **K⁺ 通道**＋釋放 NO | ↓細胞內 Ca²⁺（**不是開 Na⁺ 通道**） |
| **Ranolazine** | 抑制 **late Na⁺ current（I_Na,L）** | **間接**減少 Na⁺/Ca²⁺ 交換的 Ca²⁺ 超載；會延長 QT；不影響 HR／BP |
| **Ivabradine** | 阻斷 **funny current（I_f，HCN）** | 只降心跳，不影響收縮力、再極化、傳導 |
| β 阻斷、CCB | ↓需氧 | 見自律神經章 |

!!! tip "高頻陷阱"
    - **Nitroprusside 不易產生耐藥性**；nitroglycerin 才會（sulfhydryl 耗竭）
    - Nitroprusside 機轉是**提供 NO**，不是抑制 PDE
    - Ranolazine「**直接**抑制 NCX」是錯的 —— 是抑制 late Na⁺ 後間接減少

??? question "106-2 #69｜Ranolazine 為新穎抗心絞痛藥物，作用機轉為何？"

## 四、心衰竭藥物

### 4.1 重點整理

| 類別 | 藥物 | 機轉／考點 |
|---|---|---|
| 降低死亡率 | **ACEI／ARB**、β 阻斷（metoprolol succinate、bisoprolol、carvedilol）、**MRA**、ARNI、SGLT2i | ACEI **減緩心室重塑（ventricular dilation）** |
| MRA | Spironolactone、**eplerenone** | eplerenone 選擇性高 → **較少男性女乳症**；高血鉀；**MI 後心衰竭** |
| **ARNI** | **Sacubitril**／valsartan | sacubitril 抑制 **neprilysin** → ↓ANP／BNP／**bradykinin** 降解；neprilysin 也分解 Ang II → 必須配 ARB（**不可配 ACEI**，angioedema）；**不是直接活化 BNP 受體** |
| 重組 BNP | **Nesiritide** | **活化 BNP（NPR-A）受體 → ↑cGMP**；擴血管、利尿；急性失代償心衰竭 |
| 強心劑 | **Digoxin** | 抑制 Na⁺/K⁺-ATPase；**治療指數小**；毒性：心律不整（**DAD**，非 EAD）、噁心嘔吐、黃視；**低血鉀（loop diuretics）加重毒性**；分布體積大 → **透析無效**，用 digoxin Fab |
| | Dobutamine | β1 致效 |
| | **Milrinone**／inamrinone | **PDE3 抑制** → ↑cAMP |

!!! tip "「不是強心劑」的心衰竭藥"
    sacubitril、nesiritide、ACEI、β 阻斷、MRA、SGLT2i（empagliflozin）都**不增加收縮力**。強心＝digoxin、dobutamine、milrinone。

!!! danger "Sacubitril 必考（5 次）"
    - 抑制 neprilysin → ↑ANP、BNP、bradykinin（**會**增加 bradykinin → angioedema 風險）
    - 也會 ↑Ang II → 需併 valsartan；**適合**與 valsartan 合用
    - 擴血管、減少交感活性
    - 錯誤選項常見：「活化 BNP 受體」（那是 nesiritide）、「不適合與 valsartan 併用」、「不會增加 bradykinin」

## 五、抗心律不整藥

### 5.1 重點整理

| 分類 | 藥物 | 機轉 | 考點 |
|---|---|---|---|
| IA | Quinidine、**procainamide**、disopyramide | Na⁺＋K⁺ 阻斷 | procainamide：**藥物性狼瘡**；disopyramide：抗膽鹼、亦抑制 K⁺ |
| IB | **Lidocaine**、mexiletine | Na⁺（缺血組織） | **無抗交感作用**；MI 後心室心律不整 |
| IC | Flecainide、propafenone | Na⁺ | 結構性心臟病禁用 |
| II | Propranolol、**esmolol** | β 阻斷 | esmolol 極短效 → 手術中 |
| III | **Amiodarone** | K⁺＋Na⁺＋Ca²⁺＋非競爭性 β 阻斷 | **含碘 → 抑制 T4→T3**、甲狀腺功能異常、肺纖維化、角膜沉積；**抑制 CYP2C9 → 增強 warfarin** |
| | Dronedarone | 去碘 amiodarone | 甲狀腺毒性少 |
| | **Sotalol** | **K⁺ 阻斷**＋β 阻斷 | 延長 QT、torsades |
| | Dofetilide、ibutilide | 純 K⁺（I_Kr） | |
| IV | Verapamil、diltiazem | Ca²⁺ | |
| 其他 | **Adenosine** | A1 → 開 K⁺（I_K,Ado）、↓cAMP | **PSVT 首選**；t½ < 10 s；**不阻斷 Na⁺ 也不阻斷 K⁺ 通道** |
| | Ivabradine | I_f | 見第三節 |

!!! tip "「哪個不抑制…」秒殺"
    - 不抑制 **Na⁺**：adenosine（Ia／Ib／Ic 與 amiodarone 都抑制）
    - 不抑制 **K⁺**：adenosine（反而**開** K⁺）
    - 不抑制**交感**：lidocaine（amiodarone、sotalol、esmolol 都有 β 阻斷）

## 六、抗凝血、抗血小板、血栓溶解與止血

### 6.1 重點整理

**抗凝血劑**

| 藥物 | 機轉 | 考點 |
|---|---|---|
| UFH | 與 **antithrombin** 結合 → 中和 **thrombin＋Xa** | IV；監測 aPTT；**HIT**；解毒 protamine |
| LMWH（enoxaparin） | antithrombin → **以 Xa 為主**、對 thrombin 較弱 | 皮下、劑量好控制、**較少 HIT** |
| **Fondaparinux** | antithrombin → **只中和 Xa**（**不抑制 thrombin**） | 皮下一天一次、腎衰竭禁用 |
| **Warfarin** | 抑制 **VKOR**（vitamin K epoxide reductase）→ ↓II、VII、IX、X | 基因：**CYP2C9＋VKORC1**；**amiodarone、metronidazole 等抑制代謝 → 出血**；cholestyramine 減少吸收；監測 INR；懷孕禁忌 |
| DTI（注射） | Argatroban、bivalirudin、lepirudin | HIT 時使用 |
| DTI（口服） | **Dabigatran** | 非瓣膜性 AF；解毒 **idarucizumab** |
| Xa 抑制（口服） | **Rivaroxaban**、**apixaban**、edoxaban | 解毒 **andexanet alfa**；老人腎功能差 → **半衰期延長**（不是縮短） |

**抗血小板**

| 藥物 | 機轉 |
|---|---|
| Aspirin | 不可逆抑制 COX-1 → ↓TXA2 |
| Clopidogrel、prasugrel、**ticlopidine**、**ticagrelor** | 阻斷 **ADP P2Y12**（ticagrelor 可逆、非前驅藥） |
| **Abciximab**（單株抗體）、eptifibatide、**tirofiban** | 阻斷 **GP IIb/IIIa**（abciximab 也阻斷 vitronectin 受體）；ACS |
| Dipyridamole、cilostazol | PDE 抑制 → ↑cAMP |
| Vorapaxar | PAR-1（thrombin 受體）拮抗 |
| **Heparin 不是抗血小板藥** | |

**血栓溶解與止血**

| 藥物 | 重點 |
|---|---|
| Alteplase（t-PA）、**tenecteplase**、reteplase | plasminogen → plasmin；對 **fibrin 結合的 plasminogen** 親和力高 |
| Streptokinase | 先與 plasminogen 形成複合物；**易過敏** |
| **Plasmin 本身不能 IV 溶栓**（迅速被 α2-antiplasmin 中和） | |
| **Tranexamic acid**、aminocaproic acid | **拮抗 plasminogen 活化**（抗纖溶） |
| **Desmopressin** | V2 → 釋放 **factor VIII／vWF** → **輕度 hemophilia A**、vWD |
| Factor IX 製劑（**Idelvion** 長效） | hemophilia B |

??? question "106-2 #52｜UFH 與 LMWH 之敘述，何者**錯誤**？"

## 七、降血脂藥

### 7.1 重點整理

| 藥物 | 機轉 | 考點 |
|---|---|---|
| **Statins**（simvastatin、atorvastatin、lovastatin） | 抑制 **HMG-CoA reductase** → ↑LDL 受體 | 肌病變、肝酵素↑；抗發炎、穩定斑塊 |
| **Ezetimibe** | 抑制腸道 **NPC1L1** | 減少膽固醇吸收 |
| 膽酸結合樹脂（cholestyramine、colestipol） | 結合膽酸、減少再吸收 | 減少 warfarin、digoxin 吸收；↑TG |
| **Fibrates**（gemfibrozil、fenofibrate） | 活化 **PPAR-α** → **↑LPL**、↑apoA、↑脂肪酸氧化 → ↓VLDL／TG | 肌病變（gemfibrozil＋statin 尤其）、膽結石 |
| Niacin | **GPR109A** → ↓脂肪分解 → ↓VLDL；**↑HDL 最多** | 潮紅（PG 介導，aspirin 可減輕）、高血糖、高尿酸；**不是 PPAR-α** |
| **PCSK9 抑制**（evolocumab、alirocumab） | 單株抗體 → LDL 受體不被分解 | LDL 大降、apoB **下降**；類流感症狀 |
| **Mipomersen** | antisense → 抑制 **apoB-100** | 同型合子 FH |
| **Lomitapide** | 抑制 **MTP** → 肝臟無法組裝 VLDL | 同型合子 FH；肝脂肪 |
