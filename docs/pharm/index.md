## 讀書策略

- 每次約 **3–4 題**落在自律神經（含呼吸道 β2／抗蕈毒鹼、眼科、β-blocker 中毒）
- 題型以「**下列何者錯誤／最不適當**」為大宗 → 要熟悉每類藥的**禁忌與副作用**，不只適應症
